### Week 1 Objectives:

* Connect and get acquainted with members of the First Cloud AI Journey (FCAJ) project.
* Set up account foundation and initial cost management on AWS.
* Master fundamental knowledge of IAM, VPC, and EC2 through a series of hands-on Lab exercises.

### Week 1 Achievements:

* **Cost Management:** Learned how to use AWS Budgets to create cost alert filters (Cost) and reserved instance alerts (RI) to control the Free Tier account.

* **Identity Management (IAM):** Understood how to securely assign permissions through User, Group, and especially how to use Roles to grant temporary access.

* **Network Infrastructure (VPC):** Mastered the steps to set up a basic network environment including subnetting, routing traffic through an Internet Gateway, and tightening security with Security Groups.

* **Compute (EC2):** Successfully deployed a virtual server instance (EC2 Instance) on the self-configured network infrastructure.

* **Completed Sub-objective:** Completed all 5 hands-on Lab exercises on the learning path to accumulate knowledge and work toward receiving $100 credit from AWS.
