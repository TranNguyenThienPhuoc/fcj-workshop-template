Welcome to the **Worklog** for the E-commerce project! 

This project was carried out over a **12-week** period, starting from getting familiar with AWS cloud computing, learning how to deploy foundational services, designing an Enterprise-standard architecture, and finally building and deploying a complete **E-commer** system to a live Production environment.

Below is a summary of the 12-week roadmap:

**Week 1:** [Getting familiar with AWS and basic AWS services](1.1-week1/)

**Week 2:** [Cloud Computing with EC2 & VPC Networking](1.2-week2/)

**Week 3:** [S3 Storage Management & IAM Security](1.3-week3/)

**Week 4:** [Cloud Databases & Content Delivery (CloudFront)](1.4-week4/)

**Week 5:** [Serverless Backend Architecture (Lambda, DynamoDB, API Gateway)](1.5-week5/)

**Week 6:** [Application Containerization with Docker & Amazon ECS](1.6-week6/)

**Week 7:** [Frontend Development & User Authentication with Amazon Cognito](1.7-week7/)

**Week 8:** [AWS Well-Architected Framework & System Analysis](1.8-week8/)

**Week 9:** [Designing and Documenting the E-commerce System Architecture](1.9-week9/)

**Week 10:** [Real-world Infrastructure Setup & Core Module Programming](1.10-week10/)

**Week 11:** [CI/CD Pipeline, Domain, Security & Event-Driven (SNS/SES)](1.11-week11/)

**Week 12:** [Caching Optimization (Redis), PayOS Integration & Production-Ready](1.12-week12/)
