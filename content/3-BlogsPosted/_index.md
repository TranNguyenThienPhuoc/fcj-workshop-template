This section will list and introduce the blogs you have posted to [AWS Study Group](https://cloudjourney.awsstudygroup.com/?utm_source=zalo&utm_medium=zalo&utm_campaign=zalo). For example:

###  [Blog 1 - SESSION POLICIES IN AMAZON EKS POD IDENTITY](3.1-Blog1/)
This blog introduces the newly added session policies feature in Amazon EKS Pod Identity, which allows you to narrow IAM permissions flexibly and precisely for each pod without needing to create multiple separate IAM roles. This is an important step forward that helps apply the principle of least privilege more effectively in large-scale Kubernetes environments.

###  [Blog 2 - Web Search on Amazon Bedrock AgentCore](3.2-Blog2/)
This blog introduces the newly generally available Web Search feature on Amazon Bedrock AgentCore. It is a fully managed web search tool that allows AI agents to look up the latest information on the Internet while keeping the entire query safely within the customer's AWS environment.

###  [Blog 3 - Protecting Data on AWS with AWS Backup](3.3-Blog3/)
This blog introduces AWS Backup, a fully managed service that simplifies data backup and recovery across multiple AWS services from a centralized interface. The article breaks down its key features, practical benefits, and important considerations for building a secure and effective data protection and disaster recovery strategy.
